Thank you for raising a pull request to update the configuration of your GitHub organization.
If you are neither a member of an approval team nor of an admin team, ask one of their members to approve this PR to enable auto-merging.

The following conditions need to be fulfilled for auto-merging to be available:

- the pull request is ready for review and its latest commit has been validated without errors
- the pull request is written or approved by a member of an approval team or of an admin team
- the changes add or change no secret and no webhook that has a secret, change no setting of the Web UI, incur no cost and remove no resource
- only the configuration of the organization is modified
