<summary>Commands</summary>

- `/otterdog status [<blueprint-id>]` – update this comment
- `/otterdog status <blueprint-id> --workflow <file-or-name>` – only the jobs of that workflow
- `/otterdog status <blueprint-id> --label <label>` – only repositories whose pull request carries that label
- `/otterdog status <blueprint-id> --status failure` – only repositories with a job in that GitHub status
- `/otterdog recheck [<blueprint-id>]` – re-evaluate now, ignoring the check interval
